# Benri-Desk Agents Guide

## Project intent
- Benri-Desk is a Japanese utility tools website.
- The goal is a boring, useful, long-tail SEO asset for Japan.
- The product should feel non-AI, deterministic, fast, simple, and trustworthy.
- This is a set-and-forget style project, not a content-heavy project.
- Monetization is AdSense first.

## Product rules
- Site-facing copy must be Japanese only.
- Do not add AI features.
- Do not add accounts unless explicitly approved later.
- Keep one tool per page.
- Each tool should solve one narrow job cleanly.
- Keep pages fast, simple, and easy to trust.
- Avoid feature creep.
- Avoid trendy, startup-like, or exaggerated language.
- Do not add dashboards, gamification, or unnecessary personalization.

## SEO and content rules
- Current phase is not aggressive SEO rewriting.
- Keep content minimal but useful.
- Prefer crawlability, stability, and internal linking over cleverness.
- Avoid bloated copy, blog-style filler, and FAQ spam unless explicitly requested.
- Each tool page should include:
- a clear title
- a short explanatory intro
- the tool UI
- 2 to 3 related tool links
- a link back to its category page

## AdSense and trust rules
- The site should feel human-made, clean, policy-safe, and useful.
- Do not ship thin placeholder pages.
- Do not ship "coming soon" pages.
- Do not use deceptive language or inflated claims.
- Avoid regulated or risky tools unless explicitly approved.

## Locked exclusions
- Do not add FX or currency conversion tools.
- My Number related tools must be format and length only.
- Never imply My Number validity, identity verification, or official judgment.
- YouTube-related tools are capped and must not expand into a creator-tools platform.
- Do not make legal, medical, financial, or identity-verification claims.
- Do not add current-data tools that require ongoing maintenance unless explicitly approved.

## Category structure
- Preserve the homepage category structure:
- 1. テキスト・文字ツール
- 2. 日付・時間・営業日
- 3. Web・IT 基本ツール
- 4. CSV・データ処理
- 5. 計算・変換ツール
- 6. 日本向け実務ツール
- 7. 時間系シンプル
- 8. YouTube補助

## Current priority
- We are in a light-optimization and patience phase.
- Focus on small structural improvements, not redesigns.
- Highest ROI right now:
- internal linking
- short descriptive intros on key pages
- light title improvements on top tools
- preserving clean category structure

## Implementation preferences
- Make conservative changes.
- Do not redesign architecture unless necessary.
- Do not add dependencies casually.
- Prefer simple, maintainable, production-minded solutions.
- Keep code copy-paste ready.
- Preserve existing style and patterns when editing files.
- If suggesting new tools or features, first check them against project constraints and locked exclusions.

## Do
- Keep pages narrow, deterministic, and useful.
- Prefer small improvements over broad expansions.
- Strengthen category pages and related-tool links.
- Write concise Japanese intros where missing.
- Improve titles only when the change is clearly helpful.
- Keep the UX plain, fast, and trustworthy.
- Treat this as a long-tail utility asset, not a media brand or SaaS product.

## Don't
- Do not add AI chat, AI generation, or AI-assisted product features.
- Do not add account systems, profiles, dashboards, or retention mechanics.
- Do not bloat tool pages with excess copy.
- Do not turn the site into a content-heavy SEO project.
- Do not add risky claims, validation claims, or regulated-use positioning.
- Do not introduce maintenance-heavy features without approval.
- Do not use flashy redesigns or trendy product language.

## Future changes require explicit approval
- Adding accounts, auth, or user data storage
- Adding any AI feature
- Adding ongoing-maintenance or current-data tools
- Expanding YouTube tools beyond the current limited scope
- Adding regulated, risky, or claim-sensitive tools
- Changing the homepage category structure
- Major architecture changes
- New dependencies that are not clearly necessary
- Large-scale SEO copy rewrites
